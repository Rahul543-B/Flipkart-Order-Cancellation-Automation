# Flipkart Order Cancellation Automation

## Project Overview

This project demonstrates Selenium WebDriver automation for the Flipkart order cancellation workflow.

The automation covers navigating through the authenticated Flipkart session, accessing the Orders section, selecting an order, choosing a cancellation reason, entering the required details, and submitting the cancellation request.

## Technologies Used

- Java
- Selenium WebDriver
- ChromeDriver
- Eclipse IDE
- Git & GitHub

## Automated Flow

1. Launch Flipkart
2. Access the Orders section
3. Select the required order
4. Click on Cancel Order
5. Select the cancellation reason
6. Enter the required information
7. Submit the cancellation request

## Project Structure

- `cancel_flow_flipkart_project.java` – Selenium automation script for the order cancellation flow.
- `flipkart_selenium_Project.java` – Supporting Flipkart Selenium automation script.

## Purpose

This project was created as a hands-on Selenium automation project to demonstrate practical UI automation, element identification, XPath usage, mouse actions, dropdown handling, and end-to-end workflow automation.
